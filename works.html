共同開発

Java Servlet / JSPを使用して開発した、 4人対戦型のすごろくゲームです。 MySQLと連携したセーブ・ロード機能を備え、 ゲームの進行状況を保存・再開できる仕組みを実現しました。

使用技術

Java / Servlet / JSP / JavaScript / HTML / CSS / MySQL

担当内容

Java Servlet / JSPを用いたゲーム進行処理や、 MySQLと連携したセーブ・ロード機能の設計・実装を担当しました。 また、画面とサーバー間のデータ連携や不具合修正にも取り組みました。
